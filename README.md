# Aarav & Ananya — Wedding Invitation

A responsive animated wedding invitation built with React, Vite, Framer Motion and Lucide icons.

## Run locally
`npm install`
`npm run dev`

## Customize
Edit `src/weddingData.js` to change names, date, venue, message and event schedule. Update the calendar details and map search in `src/App.jsx` if the event information changes.

## Build
`npm run build`
